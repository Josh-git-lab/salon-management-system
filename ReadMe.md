# La Miraa Salon Management System

A web-based salon management system for managing appointments, customers, staff, services, and billing.

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Node.js
- npm

## Current Features

- Dashboard
- Sidebar navigation
- Dashboard statistics cards

## Planned Features

- Customer management
- Appointment management
- Staff management
- Services management
- Billing
- Inventory
- Reports
- Authentication
- Database integration
